# ADR — журнал архитектурных решений

Здесь копятся Architecture Decision Records по значимым развилкам проекта:
«почему выбрано именно так и какие trade-offs».

- Шаблон: [`../templates/adr-template.md`](../templates/adr-template.md).
- Именование: `NNNN-краткое-название.md` (`0001`, `0002`, ...).
- Один ADR — одна развилка; статус ведём в шапке.
- Папка живёт вне рабочей директории проекта, чтобы решения и учебные заметки
  не смешивались с кодом.
