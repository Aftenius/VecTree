# Skill: Security Review

> Вывод короткий: только то, что влияет на решение.

Проверка аутентификации, авторизации, секретов, загрузки файлов, внешних вызовов.

## Что проверяю

- **Auth**: JWT (alg, exp, аудитория), ротация refresh, отзыв токенов, защиты от replay.
- **Пароли**: Argon2 (time/memory cost), постоянное время сравнения.
- **RBAC/ABAC**: проверка на КАЖДОМ доступе к ресурсу, включая retrieval и граф.
- **Файлы**: MIME/размер/содержимое, антивирус-хук, безопасные имена, presigned URL scope.
- **Секреты**: не в репозитории, через env/secret store, не в логах.
- **Инъекции**: SQL (параметризация), prompt injection (границы системного промпта), SSRF при web scraping.
- **Rate limit / abuse**: на дорогих эндпоинтах, per-user quotas.
- **Ошибки**: не утекают внутренние детали; единый формат без стектрейсов наружу.

## Красные флаги

- Проверка прав только в UI/на одном эндпоинте.
- `LLM`-ответам доверяют как источнику прав/фактов.
- Presigned URL без ограничения по пути/типу/времени.
- Логирование токенов/PII.

## Материал для изучения

- OWASP Top 10, OWASP API Security Top 10.
- OWASP LLM Top 10 (prompt injection, insecure output handling).
- JWT best practices (RFC 8725).
