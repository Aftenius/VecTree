# Skill: Code Review (Python)

Проверка кода на уровне языка/фреймворка, независимо от архитектуры.

## Что проверяю

- **Типизация**: mypy --strict, `Protocol`, generics, отсутствие `Any`.
- **Pydantic v2**: схемы, валидаторы, настройки, сериализация.
- **FastAPI**: зависимости, статус-коды, обработка ошибок, фоновые задачи.
- **Async**: нет блокирующих вызовов в loop, корректные `async with`, отмена задач.
- **Исключения**: собственные типы, не ловить всё подряд, не глотать ошибки.
- **Инструменты**: Ruff-конфиг, единый стиль, docstring только где действительно нужно.
- **Читаемость**: имена, размеры функций, ранние возвраты, отсутствие дублирования.

## Красные флаги

- `except Exception: pass`.
- Блокирующий I/O в async-функции.
- `dict`/`Any` вместо типизированных моделей.
- God-функции и глубокая вложенность.

## Материал для изучения

- Effective Python (Brett Slatkin); Python typing best practices.
- FastAPI docs: dependencies, error handling.
