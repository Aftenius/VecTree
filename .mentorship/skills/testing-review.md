# Skill: Testing Review

Проверка unit/integration/e2e-тестов, фикстур, изоляции и CI.

## Что проверяю

- **Пирамида**: unit (домен) + integration (БД/очереди через testcontainers) + e2e API.
- **Изоляция**: тесты не зависят от порядка; чистое состояние (транзакция-rollback, фикстуры).
- **Реальность**: тесты на реальных Postgres/Redis/MinIO, а не только на моках.
- **Async**: pytest-asyncio, loop scope, отсутствие «спящих» задач.
- **Покрытие сценариев**: happy path + ошибки + границы + конкурентность/идемпотентность.
- **Скорость**: разумное время CI, параллелизм, кэш зависимостей.
- **Детерминизм**: фиксированный random/time, фейковые LLM/embeddings.
- **CI**: lint + types + tests на PR; миграции прогоняются; артефакты логов.

## Красные флаги

- Мокируют всё, включая БД → тесты ничего не проверяют.
- Нет тестов на конкурентные/повторные вызовы.
- Флаки-тесты из-за общего состояния.
- CI без прогона миграций.

## Материал для изучения

- testcontainers-python; pytest fixtures best practices.
- Property-based testing (hypothesis) для сложной логики.
- Contract testing для внешних API.
